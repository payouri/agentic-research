# agentic-research

Research on agentic coding: how to steer AI coding agents effectively, and what the
evidence actually supports.

Each topic gets a directory with three files, in this shape:

| File | Purpose |
|---|---|
| `guide.md` | The synthesis — what is true, what follows from it, and why |
| `rulebook.md` | Numbered, checkable rules, each with its test and evidence strength |
| `sources.md` | Every source, keyed for citation, with trust tier and date |

## Conventions

- **Every claim carries a source.** Verbatim quotes where the wording matters.
- **Evidence strength is labelled, always.** Peer-reviewed, vendor documentation, field
  pattern, practitioner measurement, and opinion are not the same thing and are never
  presented as if they were.
- **Conflicts are recorded, not smoothed over.** Where sources disagree — or where a
  standard's own documentation contradicts its implementers — that is the finding.
- **Unverified is stated as unverified.** Each topic ends with what could not be confirmed.
- **Findings are dated.** This field moves fast; a claim without a date is a claim with an
  unknown shelf life.
